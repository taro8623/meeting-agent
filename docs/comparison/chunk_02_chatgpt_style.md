# 議事録: A病院 CSSD 要件定義 第3回 (2026-08-07)

**参加者**: PM_A、田中、鈴木、伊藤、佐藤

## 議題
- 滅菌完了後の器材保管・ピッキングの業務フロー
- 滅菌完了後の実績登録に関する運用確認
- 使用期限管理と包装破損時の対応

## 議事内容

### 1. 滅菌完了後の保管とピッキング

滅菌が完了した器材は、清潔区域である滅菌済みエリアに移動される。担当者は専用ガウンに着替えて出入りし、器材は種類別・使用期限順に棚に整理される。

ピッキングは前日夕方に確定する翌日の手術予定表に基づき、翌朝に実施する運用となっている。緊急手術の場合は都度対応する。

### 2. 滅菌完了後の実績登録

滅菌工程を完了した際の実績登録については、滅菌器のログを日次でまとめて記録する運用となっている。滅菌器メーカーのソフトウェアが自動でログを出力しており、システム部門でもこれを把握している。

なお、電子カルテとの連携有無や実績登録の詳細なタイミングについては、次回までに部門システム担当者に確認する必要がある。

### 3. 使用期限の管理

現在、滅菌済み器材の使用期限管理は目視で行われており、稀に期限切れが発生している状況である。今後はシステム上でアラートを出せるよう機能追加を検討する。

使用期限は滅菌方式により異なり、オートクレーブ滅菌は6ヶ月、EOG滅菌は1年とする。また、包装の種類 (不織布・滅菌バッグ) によっても期限が変わるため、期限マスタの整備が必要となる。

### 4. 包装破損時の対応

保管中に包装が破損した場合、期限に関わらず再滅菌が必要となるため、包装破損時の運用フローもシステム要件に含める方針とした。

## 決定事項

- 滅菌完了後の実績登録は 滅菌器ログの日次記録により管理される
- 使用期限マスタは 滅菌方式×包装種別で整備する
- 包装破損時は 再滅菌の運用フローを組み込む
